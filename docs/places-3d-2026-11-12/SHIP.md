The sidebar uses a column grid. The map leads to **Find a work spot**, with **Walk 3D World** beside it. **Places in view** names the scope. Counts and previews sit together under category headings. Each category starts with up to three places and can expand independently. The sort control sits with filters and the visible distance label identifies the map centre. The toolbar measured 48px compared with 80px on the deployed baseline.

The old 3D entry requested the correct neighbourhood file and then looked for its street IDs in the index. That threw before the first frame. The renderer now uses the loaded area file and opens an oblique overview of the current or nearest mapped neighbourhood. Street level starts on a mapped street segment. The selector exposes all 12 areas and the footer credits the geometry and venue sources. Exact mapped heights, base heights, footprint holes and overlap decisions determine the scene. Areas with no source heights show flat outlines and fills. The view represents mapped geometry. Pedestrian access and entrances require separate evidence.

Loading, retry and return to the map work before and after the first frame. A later area request cancels an earlier one. Delayed place data updates markers for the displayed area. Escape closes the 3D dialog and preserves the task beneath it. Navigation follows manual input and clears when focus or visibility changes. Projected labels fit around the edge controls and footer.
