PLUB is agent-consumable. `/v1` is a read-only, account-free API over the evidence PLUB lawfully holds: one canonical record per venue, many time-stamped evidence records, a composite that always states its coverage, the twelve neighbourhoods, a change feed, and the source registry with licences and tiers. The tiers PLUB does not hold — commercial platform fields, individual review text, social mentions, directory crawls, private groups — are published as **absent**, never filled in. There is no Google scraping and no directory crawling; the model already has the seam where they would go. `docs/agent-api.md` names every source the design was taken from and every place PLUB deliberately diverges. The API and the interface share one rule set (`public/work-atmosphere.js`), and a test asserts they agree.

Workspace atmosphere is evidence, never a grade. `public/work-atmosphere.js` keeps five tiers apart — mapped (an OSM tag with its date), venue (what the operator claims about itself), visitor (what people who went there report), on-site (one named person's dated first-hand account of one visit), inferred (what the page computes, and says so). A dimension with no evidence stays **unknown** and is named as unknown; it never becomes zero. The composite is published only when enough of the weight is documented, and it always states its coverage and the dimensions it could not score.

A named on-site report (`public/data/venue-reports.json`) is evidence about one visit, not a standing fact about a venue. It is read by the same dimension functions as every other tier, and where a report and the open map disagree, both are shown — never averaged away. **Curated visit evidence is never written back into the signed catalogue**: `public/data/places-work.json` carries a hash the manifest publishes, and a hand-edited row would claim an OSM tag that does not exist. `test/venue-reports.mjs` locks the tier, the unknowns and the catalogue hash.

The street sketch's twelve neighbourhoods are chosen by a documented rule in `scripts/build-street-areas.py`: five authored areas keep their anchors, and the rest are the districts whose busiest 800 m catalogue cafe circle holds the most cafes, with a real mapped cafe as anchor and no overlap between areas. An anchor must be a cafe a mapped lane route actually leaves — `scripts/select-street-anchors.mjs` moves it and records the change. Geometry lives in one file per area under `public/data/street-world/`; the index carries no geometry, so opening the sketch costs the index plus one area. Heights remain explicit-tag-only; unknown stays flat.
